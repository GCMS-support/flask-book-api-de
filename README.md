# Book API mit Flask

Eine schrittweise aufgebaute RESTful-API für Bücher. Das Projekt demonstriert Flask-Routen, JSON-Antworten und die HTTP-Methoden GET, POST, PUT und DELETE.

## Start

```bash
pip install -r requirements.txt
python3 app.py
```

Die API läuft auf Port 5000. Der erste Endpunkt ist `GET /api/books`.
